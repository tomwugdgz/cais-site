GEO / AEO 五步诊断

你的网站，AI 搜得到吗？

AI 爬虫先读 HTML，再读内容。Schema 没渲染、JSON-LD 报错、实体没铺满，内容写得再好也抽不走。本工具按五步扫描全站代码层，输出问题清单、修复代码和可直接粘进 Codex 的提示词。另附 MTO 机器信任诊断：探测 MCP 端点、A2A Agent Card 与接口文档，判断 Agent 能否与你的后台通信——这部分只给诊断与建议，不给修复代码。

STEP 01
扫代码层漏洞
JSON-LD 语法、Product 字段、未渲染 metafield、robots 屏蔽
STEP 02
批量补 Schema
七层 Schema 覆盖度与 Liquid 模板方案
STEP 03
改内容结构
标题层级、答案块密度、可抽取性评分
STEP 04
铺实体与问答页
实体覆盖、独立问答页缺口、RAG 检索节点
STEP 05
信源对齐
规格口径、认证编号、跨平台一致性核对

MCP 端点、A2A Agent Card、接口文档、证据链。只诊断，不给修复
拖入或点击选择 .html 文件 支持多选。用 HTTrack / wget / Screaming Frog 导出整站后一次上传，即可诊断整个网站。
文件名会被当作 URL。建议按路径命名，例如 products_industrial-pump.html。robots.txt 可一并上传（命名为 robots.txt）。
页面已内置同源抓取通道 /api/fetch。部署到 Cloudflare Pages 后开箱即用，客户无需配置。若你直接用 file:// 本地打开，该通道不可用，请改用「上传网页文件」。
